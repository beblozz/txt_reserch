# txt-search — поисковик по текстовым файлам

> **Статус: проект готов.** Консольный режим, веб-интерфейс и тесты работают.

## Что умеет программа

- находит все `.txt` файлы в папке и во вложенных папках
- ищет одно слово или несколько слов сразу (покажет файлы, где есть все эти слова)
- ищет точную фразу
- показывает топ файлов, где совпадений больше всего, и кусочек текста с найденным местом (найденные слова подсвечиваются)
- не обращает внимания на большие и маленькие буквы
- понимает и английский, и русский текст (в том числе в консоли Windows)
- показывает, сколько времени заняли индексация и поиск
- работает в консоли и в браузере
- в браузере можно открыть найденный файл целиком и переходить между совпадениями
- можно переиндексировать другую папку, не перезапуская программу

## Как это работает

Самая простая идея — при каждом запросе открывать все файлы и искать в них слово. Но так поиск будет медленным, если файлов много.

Поэтому программа один раз читает все файлы и строит **индекс**: таблицу, где для каждого слова записано, в каких файлах и на каких местах оно стоит.

Индекс хранится в `std::unordered_map` (хеш-таблица), поэтому найти слово можно почти мгновенно, не перечитывая файлы.

Чтобы найти фразу, программа смотрит на позиции слов: если "ракета" стоит на месте 14, то "носитель" должно стоять на месте 15.

Чтобы показать топ, не обязательно сортировать все результаты целиком. Я использую `std::partial_sort` — он сортирует только нужное количество первых мест.

Для каждого слова запоминается, где оно стоит в исходном тексте. Поэтому кусочек текста в результатах показывается как в оригинале — со знаками препинания и кавычками.

## Структура проекта

```
src/tokenizer.*   разбиение текста на слова, перевод в нижний регистр
src/index.*       индекс, поиск слов и фраз, кусочки текста
src/server.*      http сервер и API для веб-страницы
src/main.cpp      консольный режим и разбор аргументов
web/              веб-страница на React
tests/tests.cpp   тесты
texts/            примеры текстов
```

## Как собрать

Нужен компилятор с поддержкой C++17 (g++ 8+, clang 7+ или MSVC 2019+).

Через CMake:

```
cmake -B build
cmake --build build
```

На Windows с MSYS2/MinGW, если CMake не находит компилятор, можно указать генератор: `cmake -B build -G Ninja` или `cmake -B build -G "MinGW Makefiles"`.
С MinGW программа собирается статически, поэтому `.exe` запускается без дополнительных DLL.

Или одной командой:

```
g++ -std=c++17 -O2 src/*.cpp -o txt_search -pthread
```

На Windows (MinGW) в конец команды нужно дописать `-lws2_32 -static`.

## Как запустить

```
txt_search [папка] [--web] [--port N]
```

| Аргумент    | Что делает                                     |
|-------------|------------------------------------------------|
| `папка`     | папка с `.txt` файлами (по умолчанию `texts`) |
| `--web`     | запустить веб-интерфейс вместо консоли         |
| `--port N`  | порт для веб-интерфейса (по умолчанию 8080)    |
| `--help`    | показать справку                               |

**В консоли:**

```
./build/txt_search texts
```

Команды в консоли:

| Ввод               | Что делает                              |
|--------------------|-----------------------------------------|
| `слово1 слово2`    | файлы, где есть все эти слова           |
| `"точная фраза"`   | файлы, где есть именно эта фраза        |
| `:top N`           | сколько файлов показывать (0 — все)     |
| `:index <папка>`   | проиндексировать другую папку           |
| `:stats`           | статистика индекса                      |
| `:help`            | справка                                 |
| `:exit`            | выход                                   |

**В браузере:**

```
./build/txt_search texts --web
```

После этого открыть http://localhost:8080

Папку `web` программа ищет сама: в текущей папке, рядом с программой или на уровень выше (если программа лежит в `build/`).
Для веб-страницы нужен интернет — React загружается с unpkg.com. Консольный режим работает без интернета.

Вместо `texts` можно указать любую свою папку. Файлы должны быть в кодировке UTF-8.

## API сервера

| Запрос                                         | Ответ                                   |
|------------------------------------------------|-----------------------------------------|
| `GET /api/stats`                               | статистика индекса                      |
| `GET /api/search?q=...&phrase=0\|1&top=N`      | результаты поиска (`top=0` — все)       |
| `GET /api/file?path=...`                       | полный текст проиндексированного файла  |
| `POST /api/index?path=...`                     | переиндексировать папку                 |

Сервер слушает только `127.0.0.1`, а `/api/file` отдаёт только файлы, которые есть в индексе.
